# Open questions

Decisions that shape the plan. Roughly in order of how much they change it.

1. **What is it, mainly?** A calm piece to watch, something to play music to, or an installation people walk through? Probably answered by trying the smallest versions of a few ideas and seeing which one grabs.
2. **Browser or TouchDesigner?** The browser (TypeScript, like the aquarium) runs anywhere and reuses aquarium code: camera, display window, corner correction. TouchDesigner is the tool to learn for projection work, but probably needs a Windows or Mac machine (unchecked). Possibly both: a browser version to find the idea, and a TouchDesigner version to learn it.
3. **Screen or projection first?** Projection is where it is heading; a screen is quicker to try things on.
4. **Fireflies or glow-worms?** Flashing flyers, Britain's steady glow-worms, or both together.
5. **Sound from a microphone or from music played in?** A microphone responds to the room; music played in directly gives a clean beat.
6. **Code shared with the aquarium:** copy the pieces needed for now, or pull a shared library out of the aquarium? The other projects plan to copy until a third project needs the same code.
