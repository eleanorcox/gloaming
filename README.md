# Gloaming

Fireflies at dusk: a field of small lights drifting and flashing, perhaps in time with music, perhaps scattering as people move past. Still a sketch of possibilities.

Gloaming is a working name, an old word for dusk.

Nothing is built yet. The plan is in [docs/](docs/README.md).
